Model Selection Experiment Plan 
Project Overview
The goal of this experiment is to explore the different machine learning models to determine whether they can improve the prediction of crisis cases within 90 days. I will be comparing the results against my existing Logistic Regression model made in Week 2 as our baseline. 


Model Candidates
These are the following models I plan to use to test:
* Majority Class Dummy - A simple baseline model that always predicts the most common class - no_crisis
* Random Forest - Combines multiple decision trees to improve the predictions
* Gradient Boosting - Builds the decision trees one after another to improve prediction performance 


Hyperparameter Search Spaces
I will test different settings for each of the models to see which combinations produce the best results.

Experiment Approach
I will be training the candidate models using cross validation and comparing their performance. I will also record the model configurations and their results in the project tracker. The ones that are the best candidates will then be evaluated on the held out validation set, and the test set will remain untouched during the model selection.


Success Criteria
My primary evaluation metric is going to be recall because it is important trying to identify as many potential crisis cases as possible. But at the same time, I will also be using F1 score to balance the recall and precision.
Here are my goals:
- Compare the results with the existing Logistic Regression baseline and Majority Class Dummy baseline
- Achieve at least 0.80 recall
- Achieve at least 0.62 F1 score


If there is a model that meets these goals, it will be considered a strong candidate to move forward for further testing.


Expected Outcome
The experiment will help determine which model will work best, which will give better results, and whether it can perform better than Logistic Regression.
